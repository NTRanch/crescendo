# Playtest record — Crescendo v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `godot --headless --script tests/run_tests.gd` (Godot 4.7.2):
  the GDScript core's engine-law suite — 28 checks.
- `node tests/core.test.mjs`: the JS realization suite — 26 checks.
  Both suites split half validation / half adversarial.
- `node tools/conformance.mjs`: JS realization vs vectors dumped
  from the GDScript core — exact integer traces.
- `node tools/playtest.mjs`: demo mode plays every level for every
  girl against the shipped realization.
- `node tools/settings-check.mjs` + `node tools/perf.mjs`: bridges
  and budget.
- D-221 visual gate: frames extracted from the FINAL preview MP4s
  (ffmpeg, −ss 6 on L1, −ss 10 on L3) at 480×480 delivery size and
  inspected against the SHOULD below.

## Results

- GDScript suite: **28/28 PASS** — tier steps exact for all four
  tiers (250/250, 438/375, 688/563, 1000/750), exactly-once under
  hold-forever and hold-through-peak, face order, girl decoupling,
  hostile-input clamps.
- JS suite: **26/26 PASS** (same law, realization side).
- Conformance: **7/7 scenarios exact, 242 samples, zero drift**;
  girl traces identical across Prima/Yui/Alma.
- Playtest: **9/9 demo runs VICTORY** (3 levels × 3 girls), steps
  1876 / 3127 / 4877 (30.0 s / 50.0 s / 78.0 s), culmination = 1
  every run, faces {REST, BUILD, F-03, F-05, F-10} all visited.
- Settings + records: round-trip and clamp PASS; settings screen
  reachable from boot with no progression PASS.
- Performance: **0.015 ms per step+draw**; page 27,340 bytes.
- Previews: 3 × 12.1 s MP4, 22,017 / 21,383 / 22,273 bytes (≤4 MB).

## D-221 visual gate

SHOULD: dark stage; one centred abstract face whose expression
reads at a glance; HUD naming level, girl, tier, phase and face
code; a progress bar coloured pink in rise and gold at the edge;
the correct prompt line for the phase (HOLD in rise, RELEASE at
the edge); weather present but quiet in T1; per-girl differences
visible (hair ring, blush size, pupil accent).

- L1 @ 6 s (F-03 edge): **PASS** — HUD reads "TIER 1 OF 2 - EDGE -
  F-03 EDGE", small pink pupils, tilted brows, open mouth, gold
  bar part-filled, "RELEASE - HOLDING SLIPS HER" prompt, sparse
  weather. Prima's plum hair ring and mid blush read clearly.
- L3 @ 10 s (T2 rise, REST): **PASS** — "FULL CRESCENDO - ALMA",
  grey hair ring, larger blush discs, salmon pupils, line mouth,
  pink bar, "HOLD TO BUILD THE RISE", weather index 1.
- Observation (not a fail): the shared 5×7 raster font's digits
  are tight at 480 px in the preview rasteriser; the shipped page
  renders text with a real monospace font and is crisp. No core
  text exceeds the raster-advance budget (all long lines ≤ size
  20; titles width-budgeted) — verified by hand against the audit
  rule x + len × 12 × round(size/14) ≤ 962 for every screen.

## Audio

Verified by code inspection only (silence rule): WebAudio is
created solely inside a user-gesture handler, tones fire solely
from core event masks caused by input, and demo mode never
initialises audio. Nothing was played aloud.
